Data for your own map

Add Coastal Watch's Stations to ArcGIS Online, ArcGIS Pro, QGIS or another mapping platform. A Station layer lists each Station's location, Coastal area and links to its operator's page and live data. It holds no Readings: for current water levels and flood levels, use Coastal Watch itself or the NOAA services below.

Oregon coast Station layer

Every Station Coastal Watch shows for the Oregon coast. These addresses stay the same; the files are rebuilt each time the site is published, so they follow the station list.

GeoJSON
CSV

Fields: operator, network, station_id, nws_id, name, kind (tide gauge, river gauge or wave buoy), coastal_area, latitude and longitude (CSV only; GeoJSON carries them as the point), station_page (the operator's page), nws_page (river gauges: the NWS page with flood stages and forecasts) and data_url (the live Readings, for a program).

Add it to ArcGIS Online

  1. Open Map Viewer and choose Add → Add layer from URL.
  2. Paste the GeoJSON address above. ArcGIS recognizes it as GeoJSON.
  3. Choose Add to map, then style it, for example by kind or coastal_area.

In ArcGIS Pro or QGIS, add the same address as a GeoJSON or CSV layer. The Stations change rarely, so a refresh interval is not needed.

Other areas

For any other Area of responsibility, open it in Coastal Watch (with Choose area on the Map, or a saved link), then use Download these Stations at the bottom of the Board. You get a GeoJSON or CSV file with the same fields for the Stations on screen. It is a one-off file, not a fixed address: download it again if the area's Stations change.

NOAA's own map services

NOAA publishes some of the same networks as ArcGIS services, kept up to date by NOAA. Add them in ArcGIS with Add layer from URL. Coastal Watch does not run these services.
